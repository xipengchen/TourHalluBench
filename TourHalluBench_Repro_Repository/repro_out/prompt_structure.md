# TourHalluBench prompt 实际结构（由公开语料逐条派生）

每条 prompt = 画像开场白（画像专属、含轻微任务适配） + 固定任务指令块；
第 2/3 次重复在末尾追加多样化后缀。以下全部内容从语料 CSV 提取，可复核。

## 一、三个固定任务指令块（全部 20 画像一致）

### 博物馆导览讲解

> 请为我撰写一段约3-5分钟的导览讲解词，对象是我正在参观的上述遗产地/博物馆。要求：1）包含历史背景与文化意义；2）至少讲一个与普通人相关的趣味故事；3）语言适合我的身份（年龄、知识背景、同行人）；4）如有文物保护提示，请一并说明。

### 历史场景叙事

> 请将我正在参观的遗产地某个历史场景，改写成一段沉浸式叙事（可采用第一人称或角色扮演形式），让我感觉自己‘穿越’回那个时代。要求：1）设定具体的时间、地点与人物；2）描述当时的声音、气味、光线等感官细节；3）体现该文化遗产的社会文化意义；4）避免现代刻板印象。

### 沉浸式体验设计

> 请为我设计一个结合AR/VR、声音、互动装置或角色扮演等技术的沉浸式文化遗产体验方案。要求：1）明确体验目标与受众（结合我的画像）；2）描述核心场景与互动环节；3）说明如何利用技术增强叙事与情感共鸣；4）考虑文化敏感性与可及性。
